# Releases

This page will walk you through the extensive release procedure for Satisfactory mods.

1. Update VersionName and SemVer in `<modid>.uplugin`

2. Update `CHANGELOG.md`

3. Commit changes to GitHub on the MAIN channel and sync changes with DEV

4. ALWAYS Verify all changes in game

5. Write patch notes

6. Release update on ficsit.app
